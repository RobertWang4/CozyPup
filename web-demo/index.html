设计改进方向（颜色延续现有 Tokens）

  • 更精致的排版层次 — Playfair Display 衬线标题 + Inter 无衬线正文，形成编辑杂志般的阅读体验
  • 卡片材质升级 — 保留 surface / surface2 / bg 三层，但增加微妙阴影和 hover 动效
  • 有机装饰元素 — 登录页飘动爪印、档案页封面图+渐变遮罩、纹理 overlay
  • 微交互系统 — 每个可交互元素都有 hover 状态、缩放反馈、颜色过渡
  • 健康数据可视化 — 宠物档案新增健康评分进度条、数据卡片网格
  • Settings 品牌化重构 — 从系统 List 升级为 Card Sections，更像个人中心
